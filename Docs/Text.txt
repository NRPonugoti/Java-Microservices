1. Circuit Breaker Questions
Q1. What is a Circuit Breaker?

Answer

A Circuit Breaker is a design pattern that prevents repeated calls to a failing service. Instead of continuously sending requests to an unavailable service, it stops the calls temporarily and returns a fallback response.

Q2. Why do we need a Circuit Breaker?

Answer

Without a Circuit Breaker:

Every request waits for timeout.
Threads become blocked.
CPU usage increases.
Other services may also fail (cascading failure).

With a Circuit Breaker:

Failures are detected early.
Calls are stopped temporarily.
The application remains responsive.
Q3. Explain the three states of Circuit Breaker.
State	Description
CLOSED	Requests are allowed.
OPEN	Requests are blocked and fallback is executed.
HALF_OPEN	Limited requests are allowed to test recovery.

        OrderRequestDto orderRequestDto,
        Throwable throwable) {

    return new OrderRequestDto();
}
